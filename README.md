# FolderCleanup

FolderCleanup is a planned utility for reviewing and organizing files safely.

## Project status

The default branch currently contains project metadata only; it does not yet
include a runnable implementation. Installation and usage instructions will be
added when the first supported release is published.

Until then, do not install packages or run scripts claiming to be an official
FolderCleanup release unless they are published from this repository.
